## 1. Module Overview

The Tax Management module centralizes all tax-related operations for hospitality businesses in Thailand. It manages VAT (Value Added Tax), WHT (Withholding Tax), and tax filing preparation in compliance with the Thai Revenue Department (กรมสรรพากร) regulations.

### 1.1 Key Capabilities

- Input Tax Register (ทะเบียนภาษีซื้อ) — VAT on purchases
- Output Tax Register (ทะเบียนภาษีขาย) — VAT on sales/revenue
- WHT Certificate management (หนังสือรับรองการหัก ณ ที่จ่าย)
- Tax filing preparation (ภ.พ.30, ภ.ง.ด.3, ภ.ง.ด.53)
- Tax reconciliation and period summary
- Tax calendar and compliance dashboard
- Support for both standard VAT (7%) and zero-rated transactions

### 1.2 GL Posting Mode

**Indirect auto-post** — tax entries are embedded within the journal entries generated by originating modules (AP, AR). The Tax Management module itself does not post to GL; it aggregates and manages the tax register data produced by other modules.

## 3. Sub-Modules

### 3.1 Input Tax Register (ทะเบียนภาษีซื้อ)

The Input Tax Register records all VAT paid on purchases (input tax / ภาษีซื้อ). Data flows from the AP module when invoices with VAT profiles are submitted.

#### Data Source

- AP Invoice (APIV) with Tax Profile = VAT07_ADD or VAT07_INC → creates Input Tax record
- AP Credit Note (APCN) → creates negative Input Tax record
- AP Debit Note (APDN) → creates additional Input Tax record

#### Tax Status Workflow

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ On Review│──▶│ Pending  │──▶│ Confirm  │──▶│ Submitted│
│          │    │          │    │          │    │          │
│ (initial │    │ (document│    │ (ready   │    │ (filed   │
│  review) │    │  verified│    │  to file)│    │  with RD)│
└────┬─────┘    └──────────┘    └──────────┘    └──────────┘
     │
     ▼
┌──────────┐
│ UnClaim  │
│          │
│ (ภาษีซื้อ│
│  ต้องห้าม│
│  non-    │
│  claimable)
└──────────┘
```

#### Input Tax Register Fields

| Field | Type | Description |
|-------|------|-------------|
| `tax_period` | VARCHAR(7) | Filing period (MM/YYYY) |
| `tax_invoice_no` | VARCHAR(50) | Vendor tax invoice number |
| `tax_invoice_date` | DATE | Date on tax invoice |
| `vendor_name` | VARCHAR(255) | Vendor registered name |
| `tax_id_13` | VARCHAR(13) | Vendor tax ID (13 digits) |
| `branch_no` | VARCHAR(5) | Branch code (5 digits, default 00000) |
| `base_amount_thb` | DECIMAL(16,2) | Tax base amount in THB |
| `tax_rate` | DECIMAL(5,2) | VAT rate (typically 7.00%) |
| `tax_amount_thb` | DECIMAL(16,2) | VAT amount in THB |
| `tax_status` | ENUM | OnReview, Pending, UnClaim, Confirm, Submitted |
| `expiry_claim_date` | DATE | Last date to claim (invoice date + 6 months) |

#### Claim Expiry Rule

$$
\text{Expiry Date} = \text{Invoice Date} + 6 \text{ months}
$$

- If current date exceeds expiry date, the system flags the record with a warning
- Recommended action: change status to **UnClaim** and reclassify as non-deductible expense

### 3.2 Output Tax Register (ทะเบียนภาษีขาย)

The Output Tax Register records all VAT charged on sales/revenue (output tax / ภาษีขาย). Data flows from the AR module and PMS interface.

#### Data Source

- AR Invoice (ARIV) with VAT → creates Output Tax record
- AR Credit Note (ARCN) → creates negative Output Tax record
- PMS Interface postings with VAT components

#### Output Tax Register Fields

| Field | Type | Description |
|-------|------|-------------|
| `tax_period` | VARCHAR(7) | Filing period (MM/YYYY) |
| `tax_invoice_no` | VARCHAR(50) | System-generated tax invoice number |
| `tax_invoice_date` | DATE | Date of tax invoice issuance |
| `customer_name` | VARCHAR(255) | Customer/guest name |
| `customer_tax_id` | VARCHAR(13) | Customer tax ID (if corporate) |
| `base_amount_thb` | DECIMAL(16,2) | Revenue base amount in THB |
| `tax_rate` | DECIMAL(5,2) | VAT rate |
| `tax_amount_thb` | DECIMAL(16,2) | VAT amount in THB |

### 3.4 Tax Filing Preparation

#### ภ.พ.30 (VAT Return)

The monthly VAT return calculates net VAT payable or refundable:

$$
\text{Net VAT} = \text{Total Output Tax} - \text{Total Input Tax (Claimed)}
$$

- If Net VAT > 0: Tax payable to Revenue Department
- If Net VAT < 0: Tax credit (carry forward or request refund)

**Filing Summary Report:**

| Item | Amount (THB) |
|------|-------------|
| Output Tax (ภาษีขาย) | xxx,xxx.xx |
| Input Tax — Claimed (ภาษีซื้อที่ขอคืน) | (xxx,xxx.xx) |
| Input Tax — UnClaimed (ภาษีซื้อต้องห้าม) | xxx,xxx.xx |
| **Net VAT Payable / (Refundable)** | **xxx,xxx.xx** |

#### ภ.ง.ด.3 / ภ.ง.ด.53 (WHT Returns)

Monthly WHT return filing for individual (ภ.ง.ด.3) and corporate (ภ.ง.ด.53) payees:

| Section | Content |
|---------|---------|
| Header | Payer information (hotel), filing period |
| Detail | List of payees with tax IDs, income types, amounts, WHT amounts |
| Summary | Total number of payees, total income, total WHT |
| Attachments | WHT certificates issued during the period |

## 4. Tax Compliance Dashboard

### 4.1 Tax Calendar

| Month Activity | Due Date | Status Tracking |
|---------------|----------|-----------------|
| WHT Filing (ภ.ง.ด.3/53) | 7th of following month | Pending / Filed |
| VAT Filing (ภ.พ.30) | 15th of following month | Pending / Filed |
| Semi-annual CIT estimate | End of 8th month of fiscal year | Pending / Filed |
| Annual CIT return | 150 days after fiscal year end | Pending / Filed |

### 4.2 Dashboard KPIs

- Input Tax claims expiring within 30 days (action required)
- Unreconciled tax invoices count
- Outstanding WHT certificates not yet filed
- VAT payable/refundable trend (6-month rolling)
- Compliance status per filing obligation
